# INV-002 · Type system — provisional implementation profile

The closed primary vocabulary is `system`, `agent`, `component`, `token`, `rule`, `invariant`, `document`, stored in a database type registry and represented by a Rust enum. A policy is `rule` with subtype `policy`; it is never an eighth primary type. There is one optional nonblank subtype and a set of role labels. Subtypes and role labels are descriptive extensions, not authorization rules or registered executable invariants.

Primary type is immutable after creation in this profile. Changes to subtype/roles pass through evolution validation and Governance. No type-specific executable payload schema (button accessibility, token value, agent execution capabilities, policy language) is invented. These require the full original specifications and future invariant evaluators.

Reconciliation status: see `reconciliation.md` and `sources/INV-002.md`. This remains an implementation profile; deferred draft features are not implied.

Since 2026-11-02 subtypes come from the fixed `mer.subtypes` list (type, subtype), added by migration. A `invariant` meron's `spec` declares `applies_to` (type and optional subtype) and a JSON Schema for the `spec` of the merons it covers; a meron must pass every applicable invariant. Invariants cannot apply to invariants, and what an invariant applies to is fixed once created. Applicability by role or location is not implemented.

Since 2026-11-02 an invariant may also name further checks with parameters (`checks`). Invariants stores them; the registry runs the ones it knows and refuses others. The first is `eio.color-role` (subtype `token/color-role`), which resolves a role's palette references and checks declared contrast pairs in both themes. Since 2026-11-03 the second is `eio.text-style` (subtype `token/text-style`), which resolves a style's fonts and size step and checks its weight, sizes and line heights. The third is `eio.reference`, which checks that a role token's path points at an admitted token of a named subtype; Eidos spacing roles use it.
