# Working in this repository

This repository holds code only: the implementation of what has been agreed.

- Notes, decisions, design pages, board scripts, explainers, reviews and research do not go here. Never add them, on any branch.
- They live in a separate, private repository. On the maintainer's machine it is the folder `Planning/` at the top of the main checkout, which this repository ignores. A worktree does not have that folder: write to it in the main checkout.
